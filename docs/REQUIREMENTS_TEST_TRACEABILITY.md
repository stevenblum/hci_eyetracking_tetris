# Requirements Test Traceability

Last reviewed: 2026-06-05

This table maps the functional requirements to automated or manual validation evidence. Hardware-dependent webcam, WebGazer, recording, and cross-browser behavior must still be confirmed with `docs/LAB_VALIDATION_CHECKLIST.md`.

Standard regression commands for this MVP are `npm run lint`, `npm run test`, `npm run build`, `npm run test:e2e`, `npm run test:e2e:installed`, and `npm run test:e2e:browser-matrix`. The browser-matrix script requires Chromium, Firefox, and WebKit to be installed through Playwright.

| Requirement(s) | Automated Evidence | Manual Evidence |
| --- | --- | --- |
| `FR-DEP-001`, `FR-DEP-002`, `FR-DEP-003`, `FR-DEP-005` | `npm run build`; `tests/e2e/app.spec.js` renders all primary SPA views. | None required for static build shape. |
| `FR-DEP-004` | Chromium Playwright suite in `tests/e2e/app.spec.js`; `npm run test:e2e:installed` runs every Playwright browser currently installed; `npm run test:e2e:browser-matrix` forces Chromium, Firefox, and WebKit on machines with those browsers installed. | Chrome, Edge, Firefox lab run in `docs/LAB_VALIDATION_CHECKLIST.md`. |
| `FR-UI-001` | Combined Setup/session panel and session-step assertions in `tests/e2e/app.spec.js`. | Lab walkthrough verifies instructions are sufficient for participants. |
| `FR-UI-002`, `FR-EYE-002`, `FR-EYE-003`, `FR-EYE-004`, `FR-ERR-001`, `FR-ERR-003` | Mock setup, camera enumeration, selected-camera validation, variable clicks per calibration point with fixed 9-point layout, camera denial/retry, real-trial setup gate, secure-origin checks, diagnostics, and Brown-style WebGazer setup unit/e2e tests in `tests/e2e/app.spec.js` and `tests/unit/recording-replay-webgazer.test.js`. | Real selected-camera setup, selected clicks per point, WebGazer preview/face box behavior, Brown calibration, Brown center precision, diagnostics export, and recalibration in `docs/LAB_VALIDATION_CHECKLIST.md`. |
